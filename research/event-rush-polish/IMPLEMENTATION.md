# Event presentation polish

The pilot retains its original gameplay and economy. Story and Dashboard now share the existing event dialog as separate views. Story uses one speaker portrait above the text, with explicit first-opening/replay state. The dashboard shows live counters/progress, a config-driven grade ladder, six animated outfit previews with ownership/free labels, pending choices and richer results. Instructions are expandable.

The first opening timer was already gated by Finish/Skip in the core. Replay legitimately showed a running clock but was not labeled. This pass explicitly labels replay, preserves deadlines, persists first-opening progress and supports returning to the dashboard without starting the event. Opening completion returns directly to the dashboard. Also fixed a pending ending automatically reopening immediately after Escape when a user had first entered the dashboard manually.

Optional B/A milestone memories unlock without interrupting brewing, queue behind an existing conversation if newly reached, and persist unlocked/read flags. Existing saves default to empty memory flags; payout records and pending rewards are retained. No dialogue is approved; see WRITING-HANDOFF.md. No NPC or new artwork was invented.

Grade cutoffs, rewards, chest odds, helper costs, supply timing and costume eligibility are unchanged. No full real-time fifteen-minute playtest was performed; focused checks use accelerated fixtures. Original events remain held, Tia still unlocks from the three beginner MAX potions, and the live panel remains in the right Events section.
